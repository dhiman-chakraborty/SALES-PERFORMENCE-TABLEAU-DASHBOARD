Sales Performance Analysis Dashboard | Tableau Project

Project Problem Statement
Businesses often struggle to monitor sales performance across different regions, customer segments, and managers due to scattered data and the lack of a centralized reporting system. The objective of this project was to create an interactive dashboard that provides a clear view of sales, profit, and quantity performance while identifying growth opportunities and underperforming areas.

Tools Used
Tableau Desktop – Data visualization and dashboard development
Excel/CSV Dataset – Data source
Calculated Fields & Filters – KPI calculations and dynamic analysis

Project Development Process
-Collected and cleaned sales transaction data.
-Imported the dataset into Tableau.
-Built interactive visualizations including KPI cards, state-wise sales maps, monthly trend analysis, segment-wise performance, and regional manager comparisons.
-Added filters and dynamic measures to improve user interaction and analysis.
-Analysis & Problem Solving

Through the dashboard analysis, I identified:
-Strong overall growth in Sales (+20.36%), Profit (+14.24%), and Quantity (+26.83%).
-Consumer segment as the highest revenue contributor.
-West region as the top-performing region, while South showed improvement opportunities.
-California and New York as major revenue-generating states.
-Profit growth lagging behind sales growth, indicating potential margin optimization opportunities.

Project Outcome
The dashboard transformed raw sales data into actionable business insights, enabling stakeholders to track performance, identify trends, optimize regional strategies, and make data-driven decisions through a single interactive Tableau dashboard.
